Integração e Entrega continua

Atividade github

  1. Inicialize o repositório com git init.
  2. Faça ao menos 3 commits significativos.
  3. Crie e alterne para uma nova branch chamada develop.
  4. Faça uma modificação, commit e merge para a branchmain.
  5. Envie tudo para o GitHub.
  6. Entregue o link do repositório via teams
